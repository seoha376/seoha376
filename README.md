## Selected Projects

### Pokémon TCG Card Translator
`Android` `Kotlin` `ML Kit` `Gemini` `Firebase`

An Android application that recognizes and translates
Pokémon trading cards using OCR and AI.

- Explores a hybrid translation pipeline using ML Kit and Gemini
- Focuses on accurate terminology and structured card information
- Designed around real-world recognition and translation limitations

### Seongsu Commercial District Analysis
`Python` `Hadoop` `Hive` `Spark`

A data engineering and analytics project exploring
business dynamics in Seoul's Seongsu district.

- Integrates commercial district and business activity datasets
- Investigates store openings, closures, and sales patterns
- Builds a data processing workflow for business insights

### Recruitment Posting Validation
`Python` `NLP` `Automation`

A project exploring how to extract, structure,
and validate recruitment posting information.

- Processes unstructured posting data
- Evaluates information consistency and eligibility conditions
- Explores automation for more reliable information discovery
